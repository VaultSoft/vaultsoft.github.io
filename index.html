FAQ

Common questions

What is VaultSoft?

VaultSoft is an independent developer making free, portable Windows utilities. Every tool is built to be simple, lightweight, and actually useful — no subscriptions, no bloat, no installers.

Are the tools free?

Most VaultSoft tools are free and open source, and always will be — no trials, no premium tiers, no hidden costs. ScribeVault is the exception: a paid privacy app with a free trial. You can support the free tools on Ko-fi if you'd like, but it's entirely optional.

Do they need to be installed?

No. Every VaultSoft tool is fully portable — just download the .exe and run it. No installer, no admin rights required, no dependencies to sort out. They even work off a USB drive.

Are they safe? Will my antivirus flag them?

All tools are safe. Because they're portable .exe files built with PyInstaller, some antivirus software may raise a false positive — this is a known quirk with Python-packaged apps, not a sign of anything malicious. Source code for the free tools is on GitHub for anyone to review. ScribeVault's source isn't public, but it never opens a network connection, and its test suite checks that on every build.

Which versions of Windows are supported?

All VaultSoft tools support Windows 10 and Windows 11 (64-bit). They work on desktops, laptops, and workstations.
